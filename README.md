QuickStore

QuickStore is a React-based e-commerce frontend that lets users browse products, search and filter items, view product details, manage a shopping cart, and complete a demo checkout.

Features

- Browse products
- Search and filter products
- Sort products
- View product details
- Add items to the cart
- Update quantities and remove items
- Complete a demo checkout
- Responsive product grid

Tech Stack

- React
- JavaScript (JSX)
- CSS
- Vite
- React Router
- Git and GitHub

Run Locally

1. Install dependencies:
   
   "npm install"

2. Start the development server:
   
   "npm run dev"

3. Open the local URL displayed in your terminal.

Note

Checkout is for demonstration purposes only. No real payment is processed.
